Privacy policy

Nightguard is a personal project for managing computer use. This policy describes its Oura integration and this information website.

Oura data

With your consent, Nightguard requests the Oura daily scope. That permission includes daily sleep, activity and Readiness summaries. Nightguard uses the current-day Readiness score to calculate the computer-time allowance. It does not request email, personal details, heart-rate streams, workouts or location.

Storage and use

The Nightguard approval service stores OAuth access and refresh tokens and the current score with its day, metric and timestamps in an operator-controlled database. Full API responses are not retained by the application. The Mac stores the signed daily score and computer-use accounting needed to enforce the allowance. Files are restricted to their intended local users.

Sharing

Nightguard sends authorization and API requests to Oura. Scores are delivered to the paired Mac; the partner approval page does not display health scores. Nightguard does not sell health data or use it for advertising. Your configured service host may process technical connection information.

Retention and removal

The score is updated as new daily data arrives. Connection tokens remain until replaced, cleared by a connection error, or removed administratively. Usage records persist for enforcement. You can revoke Nightguard access through Oura and ask the operator to remove its stored connection and usage data. Revocation alone does not erase local files.

This website

This static site is hosted on GitHub Pages. It contains no analytics, tracking scripts, forms, or Oura tokens. GitHub may process visitor connection information under its own privacy statement.

Contact

For project questions, use the project issue tracker. Do not post tokens or health information in public issues.
